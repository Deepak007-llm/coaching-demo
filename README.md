## 🎨 Design System & Highlights
* **Official Branding:** Authentic crimson maroon (`#9E1B1B`), warm golden amber accents (`#D97706`), deep academic navy (`#0F172A`), and clean ivory/white surfaces rooted directly in the real institute emblem.
* **Real Photos & Logo:** Built exclusively using the client's genuine photos (classroom gathering, official KCC podium, and student felicitation moments).
* **Strict Fact-Check Integrity:** Zero fabricated claims, no invented exam ranks, fake student numbers, or false testimonials.
* **High-Conversion Inquiries:** Fully interactive "Join a Batch" modal with client-side validation, clean success screen, and one-tap WhatsApp pre-filled inquiry redirection.
* **Interactive Lightbox:** Clicking any gallery photograph opens an immersive high-definition view with descriptive captions.
* **Fully Responsive:** Optimized for smartphones, tablets, laptops, and desktop screens.

## 🚀 How to Run the Website Demo
You can view the website directly in any browser:
1. Double-click `index.html` to open directly in Google Chrome, Microsoft Edge, or any modern web browser.
2. Or run the built-in local server:
   ```bash
   node server.js
   ```
   and navigate to `http://localhost:3000/`.
